How this page works behind the scenes on AWS

1. Static Frontend — Amazon S3

Unlike a traditional virtual machine (such as the EC2 instance running Nginx I built earlier in this challenge), this website has no always-on server to maintain. All HTML, CSS, and JavaScript files are stored as objects inside an Amazon S3 bucket configured for static website hosting.

2. Serverless Compute — AWS Lambda

When your browser loads this page, a small JavaScript snippet sends an HTTP request to an AWS Lambda function URL. Lambda spins up on demand for a few milliseconds, runs the backend logic without managing any operating system, and shuts down immediately.

3. Persistent NoSQL Storage — Amazon DynamoDB

The Lambda function connects to an Amazon DynamoDB table (visitor-counter) using a scoped IAM Execution Role—meaning zero hardcoded credentials in code. It atomically increments the visitor count and returns the updated number back to your browser.
